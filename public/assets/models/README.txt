Place .glb or .gltf robot/mech model files here.

Free CC0 model sources:
- Quaternius Animated Mech Pack (4 mechs): https://quaternius.com/packs/animatedmech.html
- Quaternius Animated Robot Pack: https://quaternius.com/packs/animatedrobot.html
- Kenney Game Assets (search "robot"): https://kenney.nl/assets

Expected filenames for preset models:
  mech_scout.glb    → "Scout Mech"
  mech_assault.glb  → "Heavy Assault"
  bot_speeder.glb   → "Speeder Bot"
  drone_cargo.glb   → "Cargo Drone"

You can also import custom .glb files via the builder UI.
